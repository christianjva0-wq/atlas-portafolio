# Atlas Digital AI — Portafolio

16 demos existentes, agrupadas por sector. El portafolio se sirve en GitHub Pages; las demostraciones enlazadas conservan sus alojamientos originales en GitHub Pages o Sites con acceso público. No se reconstruyó ninguna demo.

Los proyectos internos y los CRM de producción no forman parte del portafolio. El sistema inmobiliario y los sistemas incluidos son demostraciones. No se presentan como clientes de pago.

Fuentes e inventario: `portfolio.json`. El HTML es autocontenido con miniaturas optimizadas a partir de recursos existentes, sin servicios de pago ni generación de imágenes.

GitHub Pages: rama main, carpeta raíz.
